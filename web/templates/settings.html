{# Claude #}
前往 console.anthropic.com → API Keys → Create Key（仅显示一次，请立即复制）
格式：sk-ant-api03- 开头，约 100 个字符
{# TMDB #}
注册 themoviedb.org → 账号设置 → API → 申请 Developer Key → 填写应用信息（个人用途即可）
格式：32 位十六进制，如 a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4（不含前缀）
{# Last.fm #}
前往 last.fm/api/account/create → 填写应用名称 → 复制 API key（不是 Shared Secret）
格式：32 位十六进制
{# RAWG #}
前往 rawg.io/apidocs → 点击"Get API Key" → 免费注册（无需信用卡）→ 注册后 Key 立即显示在个人页面
格式：40 位十六进制  免费额度：200,000 次/月
{# PSN NPSSO #}
获取步骤
  1. 浏览器登录 store.playstation.com
  2. 在同一浏览器新标签页打开：ca.account.sony.com/api/v1/ssocookie
  3. 页面显示 JSON：{"npsso":"xxxxxxxx…"}
  4. 复制引号内的 64 位字符串，粘贴到下方
约 2 个月或退出 PSN 后失效，失效重复以上步骤即可

{# ── Platform Cookies ─────────────────────────────────── #}
平台 Cookie（媒体解析）

部分平台（Instagram、Twitter/X 等）需要登录 Cookie 才能解析受限内容。

如何获取 Cookie
  1. 浏览器安装 Cookie-Editor 插件（Chrome / Firefox）
  2. 登录对应平台网页版
  3. 点击插件图标 → 选择 Export → Header String
  4. 复制内容粘贴到下方对应输入框
Cookie 格式示例：sessionid=abc123; csrftoken=xyz456; ds_user_id=789…
